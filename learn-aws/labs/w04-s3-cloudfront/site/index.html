Trang này được phục vụ bởi CloudFront

Bucket S3 phía sau đóng hoàn toàn — không public, không bật static website hosting. Chỉ CloudFront gọi vào được, nhờ Origin Access Control ký request bằng SigV4.

Tự kiểm chứng: mở Developer Tools → Network → tải lại trang, tìm header x-cache.

Miss from cloudfrontLần đầu — CloudFront phải đi lấy từ S3
Hit from cloudfrontCác lần sau — trả từ cache ở edge

Thử gọi thẳng vào S3

Lấy URL S3 từ terraform output bucket_url rồi mở trong trình duyệt. Bạn sẽ nhận 403 AccessDenied. Đó là bằng chứng OAC hoạt động: bucket chỉ tin CloudFront, không tin bạn.

Security header

Response của trang này có strict-transport-security, x-content-type-options, x-frame-options — được chèn bởi một CloudFront Function chạy ở edge, không phải bởi S3.
